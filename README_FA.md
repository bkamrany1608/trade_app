# همراه معامله‌گر اندروید، بسته شروع توسعه

این آرشیو **سورس اولیه Flutter** برای اپ اندرویدِ کنترل‌پنل MT4، بدون VPS شخصی، همراه با مسیر اعلان تلگرام است. این فایل **APK نصب‌شدنی یا ربات آماده معامله زنده نیست**. محیط فعلی ابزار Flutter و Android SDK ندارد و در اینجا امکان ساخت/امضای APK وجود ندارد.

## معماری در نظر گرفته‌شده

- اپ اندروید نقش کنترل‌پنل را دارد.
- اجرای پیوسته MT4 از طریق MetaApi Cloud انجام می‌شود، نه از پس‌زمینه گوشی و نه از VPS شخصی شما.
- یک API امن در Cloud/Serverless واسط اپ با MetaApi و Telegram است. کلیدهای MetaApi و Telegram در اپ/APK قرار نمی‌گیرند.
- کد فعلی رابط اولیه و کلاینت API با دکمه‌های وضعیت، شروع/توقف، پوزیشن‌ها و پیام آزمایشی تلگرام را فراهم می‌کند. تا وقتی API متصل و مطابق قرارداد زیر ساخته نشده، درخواست عملیاتی موفق نخواهد شد.

## ساخت APK در محیط توسعه Flutter

1. Flutter SDK و Android SDK نصب کنید.
2. یک Flutter project با Android بسازید: `flutter create --platforms=android trade_companion`
3. `pubspec.yaml` و پوشه `lib/` این بسته را در پروژه جایگزین کنید.
4. از ریشه پروژه اجرا کنید: `flutter pub get` سپس `flutter build apk --release`.
5. پیش از انتشار، APK را با keystore اختصاصی خود امضا کنید و روی حساب MT4 دمو تست کنید.

## پیکربندی

در اپ، نشانی HTTPS سرویس ابری و در صورت نیاز توکن نشست اپ وارد می‌شود. توکن نشست در این نسخه فقط تا بسته‌شدن اپ در حافظه باقی می‌ماند. **توکن MetaApi، رمز MT4 و توکن ربات تلگرام را در اپ قرار ندهید و برای کسی ارسال نکنید.**

پروتکل مورد انتظار در `API_CONTRACT_FA.md` آمده است. تیم بک‌اند باید احراز هویت، مجوز کاربر، محافظت در برابر درخواست تکراری، محدودیت ریسک، لاگ ممیزی و کنترل حساب دمو را پیاده کند.

## وضعیت قابلیت‌ها

- رابط فارسی و راست‌به‌چپ: آماده در حد نمونه اولیه.
- درخواست خواندن وضعیت، شروع/توقف و فهرست پوزیشن‌ها: فقط پس از راه‌اندازی API سازگار.
- اعلان تلگرام: فقط از مسیر سرویس امن، پس از راه‌اندازی API و اتصال Bot.
- اجرای خودکار معامله، SL/TP، مدیریت ریسک و تست MetaApi: پیاده‌سازی نشده.
- APK: در این بسته تولید نشده.
